Key Features:

Add Tasks: Users can type a task and add it to the list.

Mark as Completed: Click on a task to mark it as completed (strikethrough effect).

Delete Tasks: Remove tasks individually with a delete button.

Responsive Design: Works on both desktop and mobile devices.

Interactive UI: Clean and modern interface with hover effects and visual feedback.

Technologies Used:

HTML5 – Structure of the web page.

CSS3 – Styling, layout, and responsive design.

JavaScript – DOM manipulation and event handling for interactive features.
